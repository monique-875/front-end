Sistema PetAdopt

Este é um projeto desenvolvido para a avaliação de Front-End, focado em criar interatividade para um projeto para uma ONG chamada PetAdop que é focada em encontrar lares para animais resgatados.

Tecnologias Utilizadas
HTML5 (Semântica e Acessibilidade)
CSS3 (Estilização e Feedback Visual)
JavaScript (Manipulação de DOM e Eventos)

📁 Estrutura do Projeto
O projeto foi organizado seguindo boas práticas de mercado: / ├── index.html └── src/ ├── styles/ (Estilos da página) ├── scripts/ (Lógica de interação) └── images/ (Ativos visuais)

Funcionalidades Implementadas

Interatividade Visual: Elementos que reagem ao passar do mouse (Hover e manipulação de Classes sendo os comandos mouseover e mouseout ).

Saudação Dinâmica: Mensagem de aviso sobre os plantoes e cuidados que muda conforme o horário local do usuário.

Cálculo em Tempo Real: Formulário que processa e exibe resultados assim que o usuário digita como e o caso do cadastro de resgate ele multiplica por 7 o value para obter a  idade do pet.

Injeção de Conteúdo: Adição de novos itens na tela utilizando manipulação de DOM.
